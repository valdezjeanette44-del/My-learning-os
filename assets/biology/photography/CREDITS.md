## Delivery and provenance

- Responsive local JPEG derivatives; explicit dimensions reserve layout space. Hero loads eagerly; lesson/Continue images use lazy loading and reuse the same cacheable assets.
- `manifest.json` records exact source links, licences, derivative byte sizes and SHA-256 hashes.
- Original downloaded review copies remain outside the repository. No new image-processing dependency or build step is required at runtime.
- All variants preserve aspect ratio during image preparation. CSS frames may crop edges responsively but do not distort or recolour the imagery.
- ShareAlike requirements apply to the adapted CC image assets; this record does not relicense unrelated application code. Preserve this credit record and the visible dashboard credit disclosure when distributing these derivatives.
